# Changelog

## [0.1.0] - 2026-11-13

### Added
- Initial project structure and repository setup.
- Added project description and overview.
- Defined initial project scope and objectives.
- Established the planned industrial OT architecture.
- Added initial technology stack and development roadmap.

### Project Scope
Established the foundation for an Industrial OT Edge Platform covering:

- Industrial automation and PLC-based conveyor control.
- Industrial communication using Modbus TCP.
- Linux-based edge computing with Docker.
- Industrial data acquisition and MongoDB.
- SCADA and HMI integration.
- OT cybersecurity principles based on IEC 62443.
- IT/OT integration.
