# Industrial OT Edge Platform

A practical reference implementation demonstrating industrial automation, edge computing, SCADA integration, and OT cybersecurity.

## Overview

This project explores the design and implementation of a small-scale industrial automation environment, connecting PLC-based control systems with edge computing and higher-level industrial applications.

The goal is to demonstrate how industrial equipment, operational data, and IT infrastructure can be integrated into a modern and secure OT architecture.

## Project Scope

The project is developed incrementally, starting with basic industrial control and expanding towards a complete OT/IT integration architecture.

Planned components:

- **Industrial Automation** – PLC-based conveyor control and sensor integration.
- **Industrial Communication** – Modbus TCP and industrial networking.
- **Edge Computing** – Linux-based edge server and Docker containers.
- **Data Acquisition** – Collection and buffering of industrial data using MongoDB.
- **SCADA & HMI** – Industrial monitoring and visualization.
- **OT Cybersecurity** – Security principles inspired by IEC 62443.
- **IT/OT Integration** – Connecting industrial systems with higher-level applications.

## Architecture

The architecture will evolve as new components are implemented and integrated.
